# Project 1: Time Series & Category Charts

## Overview
This project visualizes annual sales data using time series and category-wise charts using Python (Pandas, Matplotlib, Seaborn).

## Visualizations Included
1. **Monthly Sales Trend (Line Chart):** Tracks monthly aggregate sales progression over time.
2. **Category Comparison (Bar Chart):** Compares total revenue across different product lines.
3. **Category Share (Pie Chart):** Illustrates the market share percentage for each product line.

## Key Insights & Summary
- **Sales Progression:** Sales demonstrated steady activity with consistent peaks throughout mid-year periods.
- **Top Performer:** The **Electronics** category generated the highest total sales volume, contributing nearly 40% of overall revenue.
- **Distribution:** While Electronics leads, Clothing and Home & Kitchen maintain solid secondary market shares.

## Tools Used
- Python
- Pandas
- Matplotlib & Seaborn
